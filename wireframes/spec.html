System Specification (MVP)

ใบเสนอสเปกระบบ Booking Share

ระบบบันทึกและแชร์ยอดการจองห้องพักภายในบริษัท ใช้งานสะดวก รวดเร็ว พร้อมรองรับมือถือและ PWA

ลองทดสอบการใช้งานจริง (Interactive Prototype)

สามารถทดลองกดบันทึกการจอง เช็กอิน และจัดการห้องได้ทันทีบนหน้าจอจำลอง

เปิดหน้าจอทดลองใช้งาน

1. วัตถุประสงค์และประโยชน์ของระบบ

ระบบ Booking Share ออกแบบขึ้นมาเพื่อแก้ไขปัญหาการสื่อสารเรื่องการจองห้องพักภายในทีม โดยมุ่งเน้นความเรียบง่าย ไม่ซับซ้อน และทุกคนในบริษัทสามารถเปิดดูข้อมูลลูกค้าที่เข้าพักในแต่ละวันได้ทันทีจากมือถือ

📱 ใช้งานง่ายบนมือถือ (Mobile First)

เปิดเช็กยอดได้ในไม่กี่วินาที ติดตั้งบนหน้าจอโฮมเป็นแอป (PWA) ได้โดยไม่ต้องดาวน์โหลดผ่านสโตร์

🔒 ป้องกันห้องชนกัน 100%

ระบบล็อกห้องอัตโนมัติที่ระดับฐานข้อมูล ป้องกันไม่ให้เกิดการจองห้องซ้ำในคืนเดียวกันเด็ดขาด

👥 รวมยอดลูกค้าชัดเจน

แยกสถานะ "รอเช็กอิน" และ "เช็กอินแล้ว" ให้เห็นทันทีว่าวันนี้มีแขกเข้าพักจริงกี่คน

🔔 แจ้งเตือนความเคลื่อนไหวในทีม

เมื่อมีการจองใหม่ ยกเลิก หรือคืนรายการ เพื่อนร่วมทีมทุกคนจะเห็นการแจ้งเตือนในแอปทันที

* สามารถ "ยกเลิกการจอง" ได้เมื่ออยู่ในสถานะรอเช็กอิน (ห้องจะว่างให้คนอื่นจองทันที)

สรุปขั้นตอนการใช้งานสำคัญ

กิจกรรม คำอธิบายการทำงาน สถานะ
เปิดดูปฏิทินรายวัน เปิดแอปมาเห็นเดือนปัจจุบัน แตะวันที่เพื่อดูยอดรวม รอเช็กอิน และ เช็กอินแล้ว พร้อมใช้งาน
การสร้างรายการจอง 1 รายการจองสามารถเลือกได้หลายห้อง (กำหนดจำนวนคนแยกแต่ละห้อง) และระบุยอดเงินรวม พร้อมใช้งาน
การตรวจทานก่อนบันทึก มีหน้าต่างสรุป วันที่พัก, รายชื่อห้อง, จำนวนคน และยอดเงิน ให้ตรวจทานก่อนกดยืนยัน พร้อมใช้งาน
การกดเช็กอิน พนักงานกดปุ่ม "เช็กอิน" ได้ทันทีจากการ์ดหน้าปฏิทิน หรือในหน้ารายละเอียดการจอง พร้อมใช้งาน
การคืนรายการ (Restore) รายการที่เคยยกเลิก สามารถกู้คืนได้ แต่ระบบจะตรวจว่าทุกห้องต้องว่างครบตลอดช่วงพัก พร้อมใช้งาน
การจัดการห้องพัก สามารถเพิ่มห้องใหม่ กำหนดราคาอ้างอิง และเปิด/ปิดใช้งานห้องได้โดยตรงในแอป พร้อมใช้งาน

3. ขอบเขตระบบระยะ MVP (In-Scope vs Out-of-Scope)

✅ ฟังก์ชันที่มีในระบบ MVP
  • เข้าสู่ระบบสำหรับสมาชิกในบริษัท
  • ปฏิทินแสดงยอดคนเข้าพักแยก รอเช็กอิน / เช็กอินแล้ว
  • จองห้องพักข้ามคืน (1 รายการมีหลายห้องได้)
  • ระบบป้องกันการจองห้องซ้อนคืนกันอัตโนมัติ
  • ปุ่มลัดเช็กอิน และยกเลิกการเช็กอิน
  • ระบบแจ้งเตือนภายในแอป (จอง / ยกเลิก / คืนรายการ)
  • หน้าจัดการห้อง (เพิ่มห้อง / แก้ไข / เปิด-ปิดใช้งาน)
  • บันทึกประวัติผู้สร้างและผู้แก้ไขล่าสุด
⏳ สิ่งที่ยังไม่รวมใน MVP (ต่อยอดในอนาคต)
  • ระบบคิดราคาอัตโนมัติ (ปัจจุบันกรอกยอดเงินรวมเอง)
  • ระบบรับชำระเงินและออกใบเสร็จ
  • ระบบแจ้งเตือนผ่าน LINE หรืออีเมล
  • การเปิดให้ลูกค้าภายนอกจองเอง (Public Booking)
  • ระบบหลายสาขา/หลายบริษัท (Multi-tenant)

4. มาตรฐานทางเทคนิคและประสบการณ์ใช้งาน (Quality Standard)

เทคโนโลยีหลัก Next.js 14+ (App Router), Supabase, PostgreSQL 16, Tailwind CSS
การรองรับอุปกรณ์ รองรับสมาร์ตโฟนทุกรุ่น (iOS / Android), แท็บเล็ต และคอมพิวเตอร์เดสก์ท็อป
รูปแบบการแสดงผล ภาษาไทย เข้าใจง่าย แสดงวันที่แบบสากล (ค.ศ. เช่น ตุลาคม 2026)
